# Axsumawit - Guitar Mastery

A personal guitar curriculum built with React, TypeScript, Vite and Tailwind CSS.

**Site:** [axsimarosmelos.github.io/axsumawit](https://axsimarosmelos.github.io/axsumawit/)

The curriculum includes four expandable phases, 29 saved task checkboxes, embedded YouTube lessons, chord-shape and fretboard recall with spaced repetition, and one-minute chord-transition drills with score history.

## GitHub Pages deployment

This repository is prepared for **Deploy from a branch → main → /(root)** in **Settings → Pages**. The compiled site is committed at the repository root. `.nojekyll` tells Pages to serve the files directly. The editable React source is in `app/`.

No custom deployment workflow is needed. A push to the configured Pages branch publishes the committed site.

## Develop

Use Node.js 24:

```bash
git clone https://github.com/axsimarosmelos/axsumawit.git
cd axsumawit/app
npm install
npm run dev
```

Open the local URL Vite prints, including `/axsumawit/`.

## Update the published site

From `app/`, after editing the source:

```bash
npm run typecheck
npm test
npm run publish:site
cd ..
git add .
git commit -m "Update guitar curriculum"
git push origin main
```

`publish:site` builds the React app, removes the previous generated assets, and copies the new production files to the repository root. Commit the generated files with the source. Changes to `app/src` alone do not rebuild the published site on GitHub. Commit the `package-lock.json` generated by your first normal install.

## Source map

- `app/src/App.tsx`: responsive dashboard and navigation.
- `app/src/data/curriculum.ts`: phases, tasks, lesson IDs, chord diagrams, and recall prompts.
- `app/src/components/`: expandable modules, YouTube player, chord diagrams, drill timer, and recall trainer.
- `app/src/hooks/useLocalStorage.ts`: automatically persisted progress and storage-error handling.
- `app/src/lib/progress.ts`: saved-data validation and spaced-review scheduling.
- `app/tests/progress.test.ts`: five core behavior tests.

The first two phases focus on G, C, D, Em and essential strumming. Later phases introduce fretboard landmarks, recall, dynamics, and memorized performance. Week labels are suggestions; advance when milestones feel comfortable on separate days.

Progress is saved in this browser under `axsumawit.progress.v1`; it does not sync across devices. YouTube playback requires an internet connection and permission to embed from the video owner.
